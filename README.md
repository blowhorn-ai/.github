# blowhorn-ai/.github

This repository holds the Blowhorn organization's public profile and
community health files.

- The organization profile README lives at
  [`profile/README.md`](profile/README.md). GitHub renders it on the
  [blowhorn-ai organization profile](https://github.com/blowhorn-ai).
- Its images live in [`profile/assets/`](profile/assets/). Each banner and
  button has a `-light` and a `-dark` file, picked with `<picture>` and
  `prefers-color-scheme`. Character art is cut from the locked Blowhorn cast
  already published on blowhorn.ai: one character per section, only Major
  Blowhorn carries the bullhorn, no draft characters. Keep each image well
  under 400 KB.
- Blowhorn itself: [blowhorn.ai](https://blowhorn.ai) and the
  [docs](https://blowhorn.ai/docs).
- Mac download: [blowhorn.ai/download](https://blowhorn.ai/download).
